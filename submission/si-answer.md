# SI (software intelligence) answer (draft)

Yes, we used SI. The concept and the name TerraJuke ("One Earth. Every Sense. Everyone.") are our team's. We used AI assistance to refine our vision text into presentation language. The code was written with Claude Code (Anthropic's Claude, an SI coding agent) under our direction during the hackathon; every rule it implements is documented and tested in the repository. We used no SI-generated images (the only image is NASA's visualization, unmodified), no SI audio samples (all sound is synthesized at run time from NASA's pixels by deterministic code) and no SI-generated data. Any demo video assembled with AI assistance carries a visible "Edited with AI assistance" watermark and uses our own voices. No NASA branding appears in SI-assisted output. Details: SI.md in the repository.
