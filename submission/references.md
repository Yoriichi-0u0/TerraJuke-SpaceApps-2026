# Other references and tools (draft)

- NASA SVS 5313 (see nasa-data.md): the only data source.
- Björn Ottosson, "A perceptual color space for image processing" (OKLab), 2020: formulas re-implemented in `src/color.ts`.
- MDN Web Docs: Web Audio API and `navigator.vibrate` browser support (vibration offered only on supported Android browsers).
- Vite 8 (MIT): build and dev server.
- TypeScript 7 (Apache-2.0).
- Playwright / @playwright/test 1.65 (Apache-2.0): browser tests in Chromium and WebKit.
- axe-core via @axe-core/playwright 4.14 (MPL-2.0): accessibility checks.
- Node.js 24 built-in test runner.
- macOS `sips`: one-time decode of the pinned JPEG for the unit-test fixture.
- GitHub (source), Vercel (static hosting).
- Claude Code by Anthropic: SI coding agent (see si-answer.md).
- Demo video (if made): MotionGit template, credited in the video description; narration by the team.

No copyrighted third-party images, music or text are used. NASA imagery is used under NASA's media guidelines with full credit; TerraJuke is not endorsed by NASA.
