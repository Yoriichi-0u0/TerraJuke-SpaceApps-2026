# Software intelligence (SI) use

NASA Space Apps asks teams to disclose how software intelligence (AI) was used. This is our truthful account.

| Area | SI used? | Details |
|---|---|---|
| Concept and name | No | "TerraJuke — One Earth. Every Sense. Everyone." and the idea of experiencing an EIC visualization through sound, sight, text and touch are Team BoboMimi's. |
| Presentation wording | Yes | The team's vision text was refined into presentation language with AI assistance. |
| Code | Yes | The code in this repository was written with Claude Code (Anthropic's Claude, an SI coding agent) under the team's direction, during the hackathon. |
| Images | No | No SI-generated images. The only image is NASA's SVS 5313 visualization, unmodified. |
| Audio | No | No SI audio samples or recordings. All sound is synthesized at run time by deterministic Web Audio code from the NASA image's pixels. |
| Data | No | No SI-generated data. All values are computed from the NASA image by the documented rules (LIMITATIONS.md). |
| Video | — | The demo video, if made, will carry a visible "Edited with AI assistance" watermark and use the team's own narration. |

No NASA logos or branding are used in any SI-assisted output.
